# OmaPhoto — promo brief

- Product: OmaPhoto, a layered photo editor for Linux (Qt6, C++), a port of Compositor.
  Photoshop-class basics: layers, masks, blend modes, brushes/heal/clone/smudge/liquify,
  Levels/Curves/Hue-Saturation, offline AI background removal (U²-Net), PSD/HEIC import.
- Audience: Linux desktop users (Omarchy/Hyprland crowd, devs who also do photos) tired
  of GIMP; they value native, fast, offline, open source.
- Differentiators: native & fast, offline AI, follows the Omarchy theme live, MIT.
- Identity: app icon = rounded square with a blue→violet→peach sunset gradient. Default UI
  is Tokyo-Night-dark. Personality: a precise pro creative tool — calm, confident, premium.
- Look: deep blue-black backdrop with slow violet/blue/peach bokeh (the icon's gradient),
  glass and light as the recurring material, Inter (tight, heavy) + JetBrains Mono for
  eyebrows/readouts. Motion: smooth springs, precise; one fast montage for themes.
- CTA: github.com/ZacharyZhang-NY/OmaPhoto · Arch / Omarchy / Ubuntu / Fedora / NixOS ·
  free, open source, MIT.
- Sample content: "WILD" poster — lake (CC BY-SA 2.0, Wikimedia) + Mexican wolf (public
  domain, Wikimedia), text layers.
